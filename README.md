# てのひら都市

スマホのブラウザで遊べる、シムシティ風の都市づくりシミュレーションです。
発電所を建て、道路を引き、住宅・商業・工業の区画を指定して、村を「町」「市」、そして政令指定都市（人口50万人）まで育てます。

- インストール不要。`index.html` ひとつで動きます（外部ライブラリなし）
- タッチ操作に対応（1本指でツール、2本指で移動・ズーム）。PC ではマウスとキーボードでも遊べます
- 進行状況はブラウザに毎月自動保存されます
- 「ホーム画面に追加」すると全画面のアプリとして起動できます

## 遊び方

1. **発電所を建てる** — 「火力発電」または「太陽光」を選び、空き地をタップ
2. **道路を引く** — 「道路」を選んで地図をなぞる。道路は電気も運びます。川の上は橋になります
3. **区画を指定する** — 道路から2マス以内に「住宅地」「商業地」「工業地」をなぞって指定
4. **需要メーターを見る** — 画面上部の「住・商・工」のバーが伸びている区画を増やすと街が育ちます
5. **公共施設を建てる** — 公園・学校・病院は地価を上げ、高い建物が建つようになります。警察署は犯罪を、消防署は火事を防ぎます

| 人口 | 区分 |
| ---: | --- |
| 0 | 村 |
| 1万 | 町 |
| 5万 | 市 |
| 20万 | 中核市 |
| 50万 | 政令指定都市 |

### 操作

| | スマホ | PC |
| --- | --- | --- |
| ツールを使う | 1本指でタップ・なぞる | 左ドラッグ |
| 地図を動かす | 2本指でドラッグ（「調べる」中は1本指） | 右ドラッグ / WASD・矢印キー |
| ズーム | ピンチ | ホイール / `+` `-` |
| 一時停止 | 右上の速度ボタン | スペース |
| 元に戻す | 「戻す」ボタン | Ctrl+Z / ⌘Z |
| ツール切替 | 下のツールバー | 数字キー 1〜0 |

画面右の「表示」から、電力・地価・汚染・犯罪・交通量・警察／消防／学校／病院の範囲を色分けで確認できます。
「市政」では税率の変更、毎月の収支、人口と資金の推移グラフを見られます。

## 起動方法

ビルドは不要です。

- ローカル：`index.html` をブラウザで開く
- 同じ Wi‑Fi のスマホで試す：`python3 -m http.server 8000` を実行し、スマホから `http://<PCのIPアドレス>:8000/` を開く
- 公開：GitHub Pages などの静的ホスティングにリポジトリをそのまま置く（Settings → Pages → Branch を選択）

## しくみ（開発者向け）

- 64×64 マスのアイソメトリック表示を Canvas 2D で描画しています。広域表示では 8×8 マス単位で描画結果をキャッシュし、スマホでも軽く動くようにしています
- シミュレーションは1日ごとに進み、電力網（発電所からの幅優先探索）、道路アクセス、交通量、汚染・犯罪（拡散）、地価、需要（住宅・商業・工業）を計算します
- 区画は需要と地価に応じて 1〜4 段階に発展・衰退します
- 車は見た目の演出です（左側通行）
