# てのひら都市

スマホのブラウザで遊べる、シムシティ風の都市づくりシミュレーションです。
国道から道路をのばし、電気・水道・ゴミ処理を整え、住宅・商業・工業の区画を指定して、村を「町」「市」、そして政令指定都市（人口50万人）まで育てます。
街は 64×64 マスから始まり、隣の町村と合併すると 96×96、128×128 マスまで広がります。

- インストール不要。`index.html` ひとつで動きます（外部ライブラリなし）
- タッチ操作に対応（1本指でツール、2本指で移動・ズーム）。PC ではマウスとキーボードでも遊べます
- 進行状況はブラウザに自動保存されます（以前のバージョンのセーブデータも引き継げます）。claude.ai で開いてサインインしている場合は、本人だけが見られる Claude アカウント内にも保存され、ほかの端末でも続きから遊べます
- 「設定」→「データ」から保存データをファイルに書き出し、別のブラウザや端末で読み込めます
- 「ホーム画面に追加」すると全画面のアプリとして起動できます

## 遊び方

1. **国道から道路をのばす** — 地図の端から国道（4車線）が入っています。「交通」→「道路」でまっすぐなぞります。曲げるときは指を離して続きから。川は「橋」で渡ります
2. **電気・水道・ゴミ処理** — 「インフラ」から発電所・給水塔・ゴミ処分場を、道路に面した場所に建てます
3. **区画を指定する** — 道路に面したマスに「住宅地」「商業地」「工業地」を指定します。「区画・土地」には海や川を陸地にする「埋め立て」と「植樹」もあります
4. **通勤と渋滞** — 住民は道路を通って職場へ通勤します。道路が混むと渋滞し、通勤時間がのびると人は住みたがりません
5. **公共施設** — 警察・消防・医療・教育は「道路で届く範囲」と「受け入れ人数」が決まっています。街の成長に合わせて増やしましょう
6. **育たない理由を確かめる** — 「市政」→「統計」に育ちが止まっている区画が理由ごとにまとまり、「見る」でその場所へ移動します。マップ表示「発展の妨げ」では理由を色分けで確認できます
7. **市域を広げる** — 土地が足りなくなったら「市政」→「市域」で隣の町村と合併します（町になったら ¥30,000 で 96×96、市になったら ¥100,000 で 128×128）

| 人口 | 区分 | 解放される主な施設 |
| ---: | --- | --- |
| 0 | 村 | 道路・橋・バス停、埋め立て・植樹、石炭火力・風力・太陽光、給水塔、ゴミ処分場、交番・消防署・診療所・小学校、公園・神社 |
| 1万 | 町 | 大通り、ガス火力、浄水場、焼却場、警察署・病院・高校、大公園・市役所 |
| 5万 | 市 | 地下鉄駅、リサイクルセンター、大学、スタジアム |
| 20万 | 中核市 | 原子力発電所、電波塔 |
| 50万 | 政令指定都市 | — |

### 街のしくみ

| しくみ | 内容 |
| --- | --- |
| 道路 | 区画は道路のとなりだけが育ちます。住宅と職場が同じ道路網にあれば育ちはじめ、道路が隣の町村（市域の外の国道や道路）につながっていると、外への通勤・外からの通勤・工場の出荷ができます |
| 土地 | 海や川は「橋」で渡るか、「埋め立て」で陸地にできます（岸ぞい ¥80、沖 ¥200／マス）。「植樹」は地価を上げ、汚染をやわらげます |
| 通勤・渋滞 | 住民は道路で近い職場から順に通勤します。道路には容量があり（道路1,500人・大通り4,200人）、超えると渋滞して所要時間が延びます。バス停・地下鉄駅は車の通勤を減らします |
| 電気・水道 | 道路や建物を伝って届きます。使用量が能力を超えると停電・断水します。発電所には寿命があり、過ぎると発電量が落ちます |
| ゴミ | 処分場・焼却場が道路で回収します。処分場はいっぱいになると使えません。回収されない区画は地価と支持率が下がります |
| 汚染 | 工場・火力発電所・焼却場・渋滞から出ます。近くの住宅は高くなれず、住民の健康にも響きます。教育水準が上がると汚染の少ないハイテク工業が育ちます |
| 公共施設 | 道路で届く範囲と受け入れ人数があり、「市政」の予算配分で増減できます |
| 税率 | 住宅・商業・工業で別々に設定できます。人口の上限ではなく、育つ速さと支持率に効きます。12%を超えると出ていく人や会社が出ます |
| 支持率 | 仕事・通勤・空気・治安・医療・教育・ゴミ・水道・電気の満足度から決まり、住民が集まる速さに効きます |
| 目標 | 18の目標があり、達成すると交付金が届きます（「市政」→「目標」） |
| 市域 | 地図のうすい部分は隣の町村で、建物や道路はつくれません。合併すると市の土地になり、隣の町村の道路はそのまま市道になります |
| 発展の妨げ | 区画ごとに「いちばんの理由」（道路・電気・水道・仕事・働き手・通勤・汚染・治安・ゴミ・地価・需要・税・支持率など）を判定します。小さくなったばかりの区画は、その原因を表示します |

### 操作

| | スマホ | PC |
| --- | --- | --- |
| ツールを使う | 1本指でタップ・なぞる | 左ドラッグ |
| 地図を動かす | 2本指でドラッグ（「調べる」中は1本指） | 右ドラッグ / WASD・矢印キー |
| ズーム | ピンチ | ホイール / `+` `-` |
| 一時停止 | 右上の速度ボタン | スペース |
| 元に戻す | 「戻す」ボタン | Ctrl+Z / ⌘Z |
| ツール切替 | 下のツールバー | 数字キー 1〜0 |

「調べる」で区画をタップすると、育たない理由（道路・電気・水道・通勤・地価など）がわかります。
画面右の「表示」から、発展の妨げ・電力・水道・渋滞・通勤・地価・汚染・犯罪・ゴミ・警察・消防・医療・教育を色分けで確認できます。
画面上部の「電力・水道・ゴミ・支持率」をタップすると、街の統計が開きます。

### 保存データについて

- ブラウザの保存（localStorage）は、Safari で claude.ai の中に埋め込まれた状態で遊ぶと、ブラウザを閉じたときに消えることがあります（Safari の「サイト越えトラッキングを防ぐ」による制限）。そのため claude.ai では、サインインしている人の保存データをアカウントにも置き、読み込み時は新しいほうを使います
- サインインしていない人や、組織外から閲覧のみで開いている人はアカウントに保存できないため、「データを書き出す」でバックアップしてください
- 読み込めなかった保存データや、旧バージョンから変換する前のデータは、上書きせずに別のキー（`tenohira-city/v1/unreadable` など）に残します

## 起動方法

ビルドは不要です。

- ローカル：`index.html` をブラウザで開く
- 同じ Wi‑Fi のスマホで試す：`python3 -m http.server 8000` を実行し、スマホから `http://<PCのIPアドレス>:8000/` を開く
- 公開：GitHub Pages などの静的ホスティングにリポジトリをそのまま置く（Settings → Pages → Branch を選択）

## しくみ（開発者向け）

- 128×128 マスの世界のうち、市域（64→96→128 マス四方）をアイソメトリック表示の Canvas 2D で描画しています。広域表示では 8×8 マス単位で描画結果をキャッシュし、スマホでも軽く動くようにしています
- シミュレーションは市域とそのまわり6マスだけを計算するので、市域が狭いうちは軽く動きます。128×128 マスをすべて開発した場合（人口60万人超）でも、PC で1か月あたり約0.1〜0.2秒です。これ以上マスを増やすとスマホでは重くなるため、128×128 を上限にしています
- 64×64 マスの旧バージョンのセーブデータは、世界の中央に置かれ、地図の端につながっていた道路は隣の町村の道路として外へのびます
- 保存データは配列を PackBits で圧縮してから Base64 にしています（128×128 マスを開発しきっても約50KB）
- シミュレーションは1日ごとに進みます。通勤は道路網上の最短経路（ダイクストラ法）で職場に割り当て、前月の混雑度で所要時間を重み付けします。公共施設とゴミ回収も同じ道路網で、近い区画から受け入れ人数を割り当てます
- 電力・水道は発電所・給水施設からの幅優先探索で、近い順に能力を配分します
- 区画は需要・地価・汚染・通勤・働き手の充足などに応じて 1〜4 段階に発展・衰退します
- 車は混雑度に応じて増える見た目の演出です（左側通行）
